# Automated-EDW-for-cybersecurity
Cybersecurity Data Breach Analysis & EDW Automation
A capstone project focused on automating an Enterprise Data Warehouse (EDW) pipeline using Python, MySQL, and SQLAlchemy to analyze and visualize cybersecurity data breaches. The project explores breach trends, methods, and sector vulnerabilities over two decades.
Project Overview
This project analyzes over 350 publicly reported cybersecurity breach incidents to uncover patterns in attack methods, affected sectors, and data exposure scale. The goal is to enable better understanding of where existing security infrastructures are failing.
Technologies Used
- **Python** (pandas, seaborn, matplotlib)
- **MySQL** (Star schema-based data modeling)
- **SQLAlchemy** (Python-to-MySQL integration)
- **Jupyter Notebook** (Exploration & Visualization)
- **VS Code / Anaconda** (Development environment)
- Features
- Automated ETL pipeline in Python
- Star schema design (Fact + Dimension tables)
- Data stored in MySQL and queried using SQLAlchemy
- Visualizations for breach trends, methods, and vulnerabilities
- Summary insights for failure points and risk analysis
